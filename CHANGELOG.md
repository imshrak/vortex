# Changelog

## 1.2.0

- Optional window resizing with bounds, runtime sizing/positioning/scaling, visibility events, launcher branding, and configurable header actions.
- Shared font, text size, opacity, spacing, padding, corner, and animation settings.
- Tooltips, conditional rows, dependency boxes, reset methods, control destruction, and per-control persistence exclusions.
- Checkboxes, paragraphs, images, double-click confirmation buttons, multiline/validated inputs, and stepped sliders with display units.
- Dictionary dropdowns with stable IDs, disabled entries, formatted labels, required selections, and dynamic value providers.
- Collapsible groups, tabboxes, and mutable tab names, widths, and visibility.
- Modal dialogs, watermark, and a touch-accessible keybind menu.
- JSON export/import without file APIs and addon controls that can be placed in existing groups.
- Detailed customization guides and a complete advanced example.

The default compact layout and neutral header remain unchanged. Existing named configurations keep the same JSON format.

## 1.1.3

- Compact neutral settings, minimize, and close icons with circular hover highlights.

## 1.1.0

- Restored the compact page and control layout, including original spacing, sliders, toggles, dropdowns, and footer notifications.

## 1.0.0

- Initial library, examples, theme manager, and save manager.
